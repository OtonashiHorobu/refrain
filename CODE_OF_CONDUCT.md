# Code of conduct

Refrain adopts the [Contributor Covenant, version 2.1][cc] as its code of
conduct. The text below states how it applies to this project; where the two
differ, this file wins.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Scope

The code of conduct applies in every project space: issues, pull requests,
discussions, commit messages and review comments. It also applies when someone
represents the project in public.

## Expected behavior

- Assume the other person is acting in good faith and ask before concluding
  otherwise.
- Critique the change, not the person. A disagreement about a design is
  resolved with evidence: the vanilla behavior, a measurement or a test.
- Keep review comments specific. "This is wrong" is not a review; "this drops
  the packet when the queue is full, and the test at line 40 expects a retry"
  is.
- Respect the project's legal boundary. Do not ask for, post or link game code,
  game assets or datapacks in a project space.

## Unacceptable behavior

Harassment, personal attacks, discriminatory language, sustained disruption,
publishing someone's private information, and sexualized attention or imagery
are not tolerated.

## Enforcement

Maintainers may edit or delete a comment, close an issue or pull request, or
block an account. The response is proportional: a correction for a first
incident, and a ban for a pattern or for anything that endangers a person.

## Reporting

Report a conduct problem through the repository's private maintainer contact on
GitHub, not in a public thread. Reports are read by a maintainer and kept
confidential; the reporter is told what action was taken unless that would
expose someone else's private information.
